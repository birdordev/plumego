# 大规模任务调度验收要求

本页记录原方案中 66 项的目标行为和验收条件。完成状态与测试证据见 [里程碑记录](M-026.md)。

| 编号 | 实现与验收 |
|---|---|
| 01 | 生产提交接口在事务提交后才返回 `202` 和可查询的实例 ID。注入写失败、提交结果不确定、提交成功后掉线，分别验收可重试错误和同键查询恢复。 |
| 02 | 持久化表达式、时区、启停状态、版本和触发游标，启动后从存储恢复。部署前后对照定义集，确认无需人工重新注册。 |
| 03 | 以租户、调度定义和计划触发时间建立实例唯一键，在同一事务内写实例并推进游标。开启两个调度副本，在事务前后终止其中一个，验证同一时刻只生成一个实例。 |
| 04 | 每次领取分配新的 `claim_token` 或单调递增代次。ACK、Release、DLQ、续租都带上它，写入结果时也校验所有权。验收旧持有者在租约换代后无法修改当前任务。 |
| 05 | 允许任务至少一次投递。数据库内副作用使用同事务消费记录或业务唯一键，下游调用使用稳定业务幂等键或可对账的请求 ID。杀进程窗口覆盖副作用完成、去重写入、ACK 各阶段。 |
| 06 | 区分待取消、正在取消、已取消、已提交。出队后再校验状态，对运行中任务传递取消，对可控写入用条件更新守住提交点。测试取消分别发生在领取前、执行前、执行中和提交后。 |
| 07 | 已承诺任务留在持久化待处理状态，Worker 按容量领取。提交超过配额时明确拒绝，低价值触发才允许按策略合并或丢弃。压满后验证成功接收的实例都可追踪。 |
| 08 | 同库直接在事务内写任务记录；跨系统使用 Outbox 和竞争领取的投递器。验证业务回滚时无任务，提交后崩溃可补投，发出后标记失败可重投。 |
| 09 | API 从可信身份推出租户，状态更新带租户范围，Worker 访问业务资源按租户授权。对查询、取消、重放、结果下载做双租户验收，确认操作只作用于所属租户。 |
| 10 | 将任务执行结果和终态写结果分别记录，定义可重试、租约丢失、提交未知的处理，增加卡在终态写入阶段的核对流程。注入 ACK、Release 和 DLQ 写失败验证最终状态。 |
| 11 | 为续租设独立 I/O 预算，区分短暂失败和已经无法证明持有租约，超过安全窗口就取消执行。阻塞续租时验证退出、旧租约失效和新持有者接管。 |
| 12 | 限制预取与立即可用执行槽之间的差值，执行前校验租约代次和剩余时间。慢任务堵住 Worker 时，已过期的缓冲任务不得开始副作用。 |
| 13 | 对已经失去有效租约且超过 TTL 的任务定义 `expired` 迁移。明确 TTL 对正在运行任务的影响，做内存和真实 SQL 后端的一致性测试。 |
| 14 | 首期选定一种生产方言，交付版本化表和索引迁移。在真实数据库上并发启动两个 Worker，覆盖竞争领取、重启、租约过期、DLQ 和迁移前后兼容。 |
| 15 | 建立 `Schedule`、`Run`、`Attempt` 三层身份。支持从计划时刻查实例，再查该实例的所有尝试。验证同一个 Cron 并行产生多次运行时，状态和错误彼此独立。 |
| 16 | 使用显式类型及版本注册表，限制正文、元数据和引用资源大小。验证未知版本处理和新旧 Worker 滚动共存，避免旧 Worker 领取无法执行的版本。 |
| 17 | 明确固定频率、完成后延迟两套语义。固定频率从计划锚点推导，执行耗时和重试不移动锚点。用长短交替任务验证漂移。 |
| 18 | 每个计划选择跳过、合并一次或限量补跑，保存补跑窗口和决策结果。模拟停机跨过多个触发点，恢复后验证每种策略和补跑上限。 |
| 19 | 保存 IANA 时区和 UTC 计划时刻，明确夏令时的缺失小时、重复小时规则。测试时区数据变化、闰年、月底及滚动更新。 |
| 20 | 定义按计划、业务键或租户限制重叠，由共享存储原子保留执行名额。两个 Worker 同时处理相同键时验证允许、跳过和串行三类行为。 |
| 21 | 区分暂停生成、暂停领取、请求停止在途任务。保存暂停状态和生效版本，恢复由补跑策略决定。验收暂停后重启和恢复后积压释放。 |
| 22 | 更新定义使用版本比较，手动触发生成独立实例并支持幂等。定义旧版本实例的处理方式，测试两人并发修改及客户端重复触发。 |
| 23 | 生产路径以持久化实例保存下一次重试时刻及次数。区分领取次数与实际处理次数，故障恢复后预算和退避不重置。 |
| 24 | 应用声明瞬态、永久、限流和结果未知。永久失败直接隔离，限流遵循等待提示，结果未知走查询或对账。验证错误类别不靠匹配日志文本。 |
| 25 | 分别定义排队时限、单次执行时限和总重试时限，明确超过时限后的状态和副作用处理。验证慢任务按正确的时限退出，区分超时和正常停机。 |
| 26 | 在 Worker 任务边界回收槽位和续租资源，产出脱敏失败原因并按策略重试或隔离。触发一个处理器 panic 后验证后续任务继续消费。 |
| 27 | 记录实例启动 ID、执行池和版本，用于诊断与节点识别。任务写入权限继续由每次领取代次决定。测试同名实例上线和下线时各自可追踪。 |
| 28 | 扩展独立参考模块，增加调度角色。API 负责任务命令和查询，调度器负责生成实例，Worker 调用共享业务服务。验收三类角色可独立扩容、升级和停止。 |
| 29 | 检查 schema、注册表和存储连通性，记录可恢复和需隔离的任务。关键恢复失败时保持未就绪，返回可诊断原因。测试部分数据损坏、缺少处理器和恢复卡住。 |
| 30 | 依次撤销就绪、停止领取、排空、发出取消，再释放可安全交接的租约。对仍在执行副作用的任务依靠代次和业务幂等保护。用真实 SIGTERM 和超时强杀验收。 |
| 31 | 生产死信按实例和尝试保留失败快照、类型版本、原因和关联 ID。验证同一计划连续失败、服务重启后，多个实例都能被单独定位。 |
| 32 | 支持按租户、任务类型、失败码和时间预览，默认限批、限速并保留原代次。验证毒任务不会在重放与 DLQ 间无限循环。 |
| 33 | 公共 API 只返回稳定错误码和安全摘要，受控诊断记录使用脱敏字段，限制错误长度。注入含敏感数据的下游错误，检查 HTTP、日志和死信。 |
| 34 | 管理变更写入持久审计，记录操作者、租户、请求 ID、前后版本及原因。验证审计提交失败时操作结果符合约定，并能区分业务审计与执行日志。 |
| 35 | 按租户和操作存幂等键、请求指纹和实例 ID。相同请求重放同一结果，同键不同内容返回冲突。验证成功响应丢失后的恢复。 |
| 36 | 在共享存储上做有索引的游标分页，稳定排序用时间和 ID，精确总数按需计算。验收大表深分页延迟以及并发写入时的翻页行为。 |
| 37 | 先生成带数量和筛选范围的操作计划，异步分批执行，保存进度和失败项。测试暂停批次、重复提交及执行期间部分任务版本变化。 |
| 38 | 增加每租户待处理任务数、计划定义数、待处理字节等额度，提交事务内保留或释放额度。并发提交、取消、过期后验证额度账实一致。 |
| 39 | 分开记录计划触发延迟、可领取到开始、执行耗时和终态提交延迟。按队列、任务类型、结果分类，实例 ID 留在日志与追踪。 |
| 40 | 持久化有限的关联字段，Worker 新建有截止时间的上下文并链接提交追踪。验证重试、重放可查到源请求，且不会把请求凭据带进任务。 |
| 41 | 为调度延迟、最老可运行任务年龄、终态写失败、续租失败、DLQ 增速定义 SLO 和告警。用空闲、持续积压和存储故障三个场景验收。 |
| 42 | 写清 RPO、RTO、重连和主从切换期间的读写规则。切换时核对新主节点的实例、租约、Outbox 和结果，分别统计重复投递与实际重复副作用。 |
| 43 | 将过期清理拆成分区限量扫描，领取仍用条件过滤不合格任务。对比大量过期记录时的锁等待、事务耗时和领取 p99。 |
| 44 | 用生产形态数据对待领和租约过期分支分别做执行计划分析，补稳定排序键。记录估算偏差、扫描行数和锁冲突。`SKIP LOCKED` 已是现有能力。 |
| 45 | 用空闲退避、抖动和最早可见时间降低查询密度。需要时加跨进程通知，并保留周期探测补偿。对比空队列数据库 QPS 和入队到领取延迟。 |
| 46 | 先对高频短任务验证批量写入和合并 ACK，逐条保留代次条件及结果。测吞吐、尾延迟、失败后重试范围和 WAL 增量。 |
| 47 | 持久化调度表按分片和 `next_fire_at` 查小批候选，各副本只负责当前拥有的分片。测试分片转移期间实例连续性、接管延迟和锁竞争。 |
| 48 | 对允许延后的任务使用可重现的抖动，按租户拆分热点，在严格时间窗内逐批展开。用同一时刻密集触发验证最长延迟。 |
| 49 | 引入老化、保底份额或分优先级队列的加权领取。让高优先级持续进件，验证低优先级最长等待仍有上界。 |
| 50 | 给租户、任务类型、下游依赖配置全局并发和速率预算。在领取或开工时原子保留槽位，故障后可回收。并行扩容时测下游实际峰值。 |
| 51 | 分开 CPU 密集、长 I/O、短任务等执行池，独立并发、连接池、部署和扩容指标。验收长任务压满时短任务 SLO 仍达标。 |
| 52 | 对仍使用进程内 Scheduler 的场景，测改期、取消、远期任务的堆积。按证据增加主动删除、定期压缩或有限时间窗口。 |
| 53 | 区分在途、终态、尝试和审计的保留期。按时间归档或分区清理，聚合指标异步更新。用目标数据量测表膨胀、归档耗时，以及监控查询对领取延迟的影响。 |
| 54 | 结果元数据留在任务库，大文件使用受租户约束的对象引用；进度按时间和增量节流。验证下载授权、过期清理和高频进度写入成本。 |
| 55 | 结合最老可运行任务年龄、到达率、处理率、并发饱和度和下游余量扩容，缩容复用排空。验收突发流量、降级和缩容接管。 |
| 56 | 建立真实数据库多进程压测，覆盖短任务、长任务、定时风暴、热点租户、重试风暴和数据库切换。输出持续吞吐、p99、峰值积压、恢复时间和资源成本。 |
| 57 | 按流程实例持久化节点和边，前驱终态与后继就绪原子衔接。重启后验证跨节点依赖和同一 DAG 多实例隔离。 |
| 58 | 保存等待状态、截止时间、信号关联键和权限，释放 Worker 槽位。测试信号提前、重复、迟到和服务下线后恢复。 |
| 59 | 把大批次分页展开，限制同时创建的子实例，通过持久屏障收集结果。测试部分失败、取消和百万级子项的内存上限。 |
| 60 | 保存分片游标、输出版本和代次。杀死 Worker 后从最近确认点继续，验证未提交分段可安全重跑。 |
| 61 | 为已提交副作用登记可重试的补偿步骤，使用独立幂等键。注入正向成功、补偿失败和人工接管，核对最终业务状态。 |
| 62 | 让流程实例关联兼容版本，建立回放测试或并行 Worker 版本路由。旧流程跨发布继续推进，新流程采用新版本，回滚可重复验证。 |
| 63 | 持久记录事件位置和消费进度，按事件 ID 去重，处理乱序、迟到与重放。现有事件参考应用可作为业务装配起点。 |
| 64 | 将业务日历独立版本化，定义例外日期、跨时区与变更后的生效范围。用节假日跨月、调休、日历升级生成可复核的触发清单。 |
| 65 | 优先定义租户或分片的主地域和写所有权。演练地域隔离、单侧接管、回切和跨地域副作用去重，再评估双活。 |
| 66 | 使用独立执行环境和最小权限，限制 CPU、内存、运行时间、文件与网络访问。验收超额终止、凭据隔离、意外退出和资源回收。 |
