# 状态与提交边界

- KVM 故障隔离从 `pending` 经独立核对进入 `fenced`，部署平台在申请时推进代理代次并禁止后续派发。现场恢复申请进入 `rejoin_pending`，拒绝回到 `fenced`。无未决写入且替换代理仍获授权时，批准会替换主体并再次推进代次，宿主机继续排空，直到管理员恢复且收到新上报。隔离决策、现场证据摘要与宿主机变更同事务提交。
- KVM 隔离任务清单与重新接入审批使用相同的阻塞条件。虚拟机恢复固定隔离代次和任务版本。独立审批与虚拟机观测、容量预留状态同事务提交。确认仍有持久域时保留预留。按两份证据确认缺失并结束任务时归还容量及地址，继续保留启动卷。
- KVM 冷迁移固定源 VM 版本、已登记备份、目标预留和代理代次。批准事务消费目标预留、更新同一 VM 的放置和版本并置为 `queued`。源启动卷保留，旧预留的提交重放仍返回同一 VM。目标通过现有写入许可及读回路径进入 `running`。
- KVM 故障疏散另固定源隔离代次。批准事务转移原 IPv4、归还源端计算预留、保留启动卷，并把源接入阻塞与目标入队一起提交。独立现场清理确认完成后，源宿主机才能批准重新接入。
- KVM 疏散自动选址在受理事务排除源故障域，写入目标预留和待审批申请。相同申请重放返回原预留。拒绝时同时释放仍有效的自动预留，批准沿同一疏散确认链路执行。
- KVM 批量疏散在同一事务写入宿主机批次、各 VM 的迁移申请及目标预留。任一项失败回滚整批。批次固定成员和顺序，查询显示各项当前审批及清理状态。每台 VM 的迁移批准仍单独提交。
- KVM 疏散预案登记为 `armed`。独立确认对应源隔离代次时激活，数据库领取事务负责转为 `submitted`、`failed` 或记录重试原因。管理员可在批次提交前将预案转为 `cancelled`。批次提交与预案回执同事务提交，VM 执行仍由独立审批触发。
- KVM 宿主机镜像回执按代理代次和版本更新。`verified` 可经当前版本的新验证续期，`missing` 立即撤销可用性。要求验证的迁移在选择目标及批准时都持有目标宿主机行锁，并核对该代次的有效回执。过期或撤销不会转移源预留。
- KVM 共享磁盘放置依次锁定网络、共享池和候选宿主机，同一事务核对预算、封存已经到期的预留并写入新的预留。绑定持续扣账，退役后的保留卷继续计入共享池，宿主机的计算资源与 IPv4 按原状态机释放。
- KVM 实时迁移依次写入 `pending`、`approved`、`dispatched`、`source_departed`、`completed`。独立批准后保留目标计算容量，目标代理准备后才可给源代理签发一次性派发。源域消失、随后目标持久域运行是切换归属的提交条件。派发前可拒绝，派发后需两端独立确认隔离并登记现场证据才可终止。已派发以及未结算的状态保留原 VM 和目标预留。
- KVM 保留卷清理按历史放置登记，依次经过 `pending`、`approved`、`dispatched`。第二次确认缺失后，`completed` 与清除保留占用同事务提交。卷重新出现会清除第一次缺失记录。确认隔离后可根据独立现场证据结算缺失，或以 `aborted` 保留原卷。

- 裸金属回收从 `requested` 进入 `approved` 或 `rejected`。独立审批后，固定代次的站点服务 30 分钟内仅能从 `approved` 领取一次并进入 `claimed`。领取后的关机盘点和证据摘要将状态推进为 `verified`。归属转移同事务消费为 `consumed`。领取后的超时或服务失联保留操作限制。已有开机历史的设备每次跨项目转移需要新的清理凭证。
- 回收恢复申请附着在 `claimed` 状态上。旧领用授权失效后可提交隔离与清理证据，回收保持 `claimed`。独立审批人核对该申请并确认新关机盘点后，同一事务记录恢复决定、审计和回收 `verified` 状态。拒绝保留冻结并允许提交新恢复申请。

- 裸金属部署关联成功的 PXE 配置和待审批的开机任务，初始为 `pending`。开机前核对安装器权限及启动设置，关机状态下的一次性 PXE 作为派发前提。确认开机和覆盖消费后，指定安装器可提交 `installed` 或 `failed`。待回报部署到期显示 `expired`，同一终态收据可重放。

- 裸金属一次性 PXE 沿用电源操作账本及物理 UUID 互斥。独立审批后登记派发，再以强 ETag 对已关机系统发送一次条件更新。只有读回对应配置才标记成功，回执不明和版本冲突沿只读路径收敛。后续开机和部署进度独立记录。

- 裸金属电源申请从 `awaiting_approval` 经独立审批进入 `queued`。Worker 复核工单、授权与物理 UUID 后先持久登记 `applying`，然后至多派发一次。恢复已登记操作时只读观察。确认目标状态后同事务更新盘点、操作账本与发件箱，观测不充分转到 `needs_review`。独立复核可重新进入 `observing`。

- KVM 宿主机登记后，需要有效代次、递增序号和 90 秒内的容量样本才可放置。管理员排空或换绑后停止新预留。换绑增代，恢复要求重新观测。放置按宿主机串行核算所有代次的有效预留。同键重放不增加预留。释放与过期回收后原收据可追溯，已被重新分配的过期预留持久封存。
- KVM 创建把有效预留和启动卷同事务绑定。任务依次经过 `awaiting_approval`、`queued`、`defining`、`defined`、`starting`、`running`。独立审批人可拒绝仍未登记外部写入的任务。每次从 `queued` 或 `defined` 出发只产生一个写入授权。缺失、不符与连接中断均保留原阶段和容量，仅匹配同一域定义后推进。再次轮询已登记的步骤时只读核对。
- 站点镜像拉取依次读取登记、下载至临时文件、校验长度与摘要、复查登记和读权限并原子发布。重复拉取核验已有目标，完成回执仅在验证和持久化后生成。镜像分发不推进 VM 状态。
- 镜像创建在 `queued` 和 `defining` 之间增加 `staging`、`staged`。重复准备必须重新核对当前身份及审批。现有目标只有摘要、长度及链接证据匹配时才可采用。刷新存储池后观察到正确卷才进入 `staged`，保留原预留直到现有创建或退役路径收敛。
- KVM 关机从 `running` 进入 `shutdown_requested`，独立审批后为 `shutdown_queued`。审批人在申请阶段或尚未登记关机授权时可拒绝，返回 `running`。单次授权将任务转到 `stopping`，确认同一持久域关机后转到 `stopped`。观察失败维持 `stopping`，全部阶段保留原预留。
- KVM 退役从 `stopped` 进入 `retire_requested`，独立审批后为 `retire_queued`，单次写入授权后为 `undefining`。两轮带版本的缺失观测确认后，在同一事务转为 `retired`、释放放置预留及登记审计。观察到域仍存在时重置缺失进度。保留的启动卷仍有唯一绑定保护。
- KVM IPv4 与放置预留一同受理。地址池按项目和站点串行分配，数据库唯一约束阻止跨宿主机争用。未绑定的过期地址在复用前持久封存旧预留。已绑定地址跨 TTL 与关机继续占用，退役确认或未派发的创建申请被拒绝时归还。
- KVM 静态 DHCP 配置以不可变地址池为期望。宿主机绑定代理按两个 libvirt 视图计算缺失项，每次写入前复核代次，只追加缺失映射。完成由只读观测确认，部分应用可从现有视图续跑，地址预留的状态与有效期沿用原合同。
- 已纳管域容量采样只读取账本和 libvirt。核对域清单、持久与运行配置以及已绑定的预留后，可上报非零容量。未知域或证据漂移时上报零容量。平台应用报告前在宿主机锁下复核管理版本及正向的域证据。采样不改变 VM 状态，也不释放任何预留。
- 云账号创建于待校验，身份校验后为只读。写入启用需要能力验证和授权。停用或撤销后停止发起厂商调用。凭据轮换提高代次。
- 同步运行从领取进入扫描，每页数据和游标在同一事务推进。相同作用域的旧代次无法继续写入。失效游标使扫描进入重启，失败页保留既有本地结果。缺失候选来自完整扫描，移除确认使用权威读取并再次核对候选观测版本。
- VMware vSphere 在当前会话取完指定数据中心的所有 PropertyCollector 页后开始本地提交。跨会话使用作用域与内容指纹复核旧检查点，指纹变化使扫描新开代次。权限范围内未返回的对象保留为缺失候选。
- 安全组规则按同一账号和地域内的父组授权读取。父组不可见、归属待确认或目标项目失去账号授权时隐藏子规则。父组重新可见或移转后，在下一次查询时应用新归属，无需重新盘点子规则。单次厂商点查无法确认缺失时保留候选。
- 云盘快照从同账号同地域的源卷投影项目归属和版本。源卷转移后，快照读取同步应用新的项目归属。已有源卷关系发生冲突时，整页回滚并保留检查点。移除源卷后保留快照已确认的归属，拓扑隐藏已移除的卷节点。
- 操作从待审批或已入队进入执行、观测、成功或确认失败。提交后断连进入结果待确认。安全重发使用原作用域、参数和厂商幂等标识。无法判定的步骤转人工处置并保留预留。
- 腾讯云 CVM 退役在受理事务预约实例与系统盘并固定归属版本。独立审批后，Worker 通过 CVM 和 CBS 点查核对关机、按量计费、销毁保护和唯一系统盘，再登记发送一次。有效回执以及连续两轮双接口完整空集共同构成自动确认条件。回执丢失转待复核。终态、实例移除、配额释放和发件箱同时提交，系统盘通过独立盘点收敛。
- 托管数据库改名固定同地域数据库的产品、原名称、期望名称和归属版本。审批和发送前重新验证授权，Worker 先完成厂商点查再登记发送。进入执行后只读观测，目标可操作且同一实例返回期望名称时，原子发布资产名称和操作终态并使早期盘点领取失效。待复核保留归属预约，仅独立审批人可恢复对账。
- 托管数据库时间点恢复固定源数据库和隔离目标放置。审批、工单和原生可恢复时间及规格复核通过后登记 `applying`，至多派发一次。已登记但缺少目标和任务回执时进入 `needs_review`。完整回执允许独立审批人只读续查，成功结算时原子登记新资产归属、保留源实例并发布终态事件。未决操作保留源数据库归属预约。
- 阿里云 MySQL 克隆在同一恢复状态机内使用持久操作 ID 作为厂商 `ClientToken`。对账绑定厂商返回的新实例 ID，核对目标放置、私网端点、继承的白名单和磁盘加密。断连后保留归属预约和待复核状态。
- 托管缓存改名固定地域、Redis 兼容产品、原名称、期望名称和归属版本。持久登记发送后只允许点查对账。待复核保留归属预约，独立审批人恢复观测后以厂商同一实例的期望名称和可操作状态确认成功。确认事务使早期盘点领取失效，并发布缓存终态事件。
- 本地受理事务同时提交意图、操作、预留、审计和待执行队列。终结事务核对租约代次并提交观察结果、配额结算和发件箱。外部调用在数据库事务外执行。
- 独立数据盘创建固定账号、可用区、存储类型、容量和加密要求。独立审批后复核放量与可用区再登记派发。恢复已登记任务时只读核对唯一标记、稳定状态及匹配的规格和计费模式。证据不足保留待复核和活动操作额度。确认后同事务登记单块新盘、归属、拓扑及终态事件并隔离早期扫描。
- 实例规格变更固定原规格、目标规格、实例归属版本及腾讯云自动启动确认。独立审批后核对远端停机、计费、原规格及当前可变配候选，登记 `applying` 后单次派发。只读确认目标规格和厂商规定的结果状态后，同事务更新盘点、历史、终态与发件箱，并废弃旧盘点。证据不足进入 `needs_review`，复核仅允许再次观测或按证据结束。
- 云盘扩容固定归属版本、原容量和目标容量，独立审批后复核远端按量数据盘的用途、挂载状态和原容量。持久登记 `applying` 后最多派发一次，恢复后只读核对原盘容量。华为云带回执时还核对 EVS 任务终态。活动或待复核操作与挂卸盘、快照变更和退役互斥。确认时在同一事务写盘点、历史、终态和发件箱，同时废弃早期扫描。
- 独立数据盘释放固定盘 ID、归属版本和容量。独立审批后复核本地依赖和厂商快照及磁盘状态。登记派发后只读观测，异常或仍可见时重置缺失次数。两轮精确缺失后原子更新盘点、历史与终态事件，隔离先前扫描。保留厂商回收后重新盘点的能力。
- 云盘快照创建固定源卷归属版本和挂载卷授权，必须独立审批。同一源卷的活动快照创建与挂卷、卸卷互斥。Worker 先点查云盘状态，再提交 `applying` 状态和发送记录。此后只读对账，匹配唯一关联标记、源卷与可用状态后，在同一事务登记快照资产、隔离旧盘点结果并提交终态事件。
- 云盘快照删除固定快照标识、源卷关系及源卷归属版本，必须独立审批。Worker 确认云端快照可删除后记录发送。两轮连续的完整精确查询均返回空结果，才在持有当前任务租约时原子记录资产删除、操作终态和发件箱事件。查询错误清空累计缺失次数，人工续查只进行读取。
- 快照恢复审批固定源快照和源卷归属版本以及新云盘规格。Worker 在记录发送前核对源快照的大小、加密状态和账号容量上限。请求发出后只读查询一次提交对应的恢复卷，唯一有效证据与可用状态就绪后，在同一事务登记新卷归属、来源拓扑和终态。后续云盘盘点保留已确认的恢复来源。
- 系统盘镜像制作在同一事务保存源实例版本、操作及预约。发送前必须重新确认本地权限、审批和厂商关机状态。Worker 持租约登记发送，再按原范围只读核对关联标记和回执。资产归属、源实例拓扑、终态发件箱和预约释放共同提交。待复核保留预约。
- 跨地域镜像复制固定源资产版本、目标账号和地域以及两端凭据代次。审批、发送和确认均重新校验授权。活动复制占用源镜像预约，待复核保留预约。对账使用厂商回执或可验证的唯一关联标记，确认后在目标范围登记资产，与操作终态、发件箱事件和预约释放同事务提交。源与目标通过操作账本关联。
- VPC 和子网删除从 `awaiting_approval` 开始。删除活动期间使用操作互斥阻止新的依赖写入。子网按父 VPC、子网的顺序锁定，审批与发送前复核目标与父资源归属版本。厂商请求至多发送一次。两次连续完整的精确缺失证据与资产删除标记、`succeeded` 和发件箱事件一起入库。中断证据清零，`needs_review` 保留互斥并可由独立审批人恢复只读观测。
- 自有镜像删除固定镜像标识和归属版本，需独立审批。占用镜像的实例申请、已纳管实例和启用模板均阻止删除。新建实例、发布目录和显式转移归属在锁定镜像后检查活动删除操作。Worker 先核验厂商镜像再提交发送记录，连续两次确认缺失后原子写入删除标记、操作终态与发件箱事件。复核重试只读。
- 原卷回滚审批固定快照、原卷和归属版本，申请时须显式确认覆盖。原卷与快照变更和挂卸载互斥。Worker 点查未挂载数据盘，持租约提交发送记录后只发送一次。华为云 V5 读取原回执的项目级 Job，终态须匹配回执 ID 和目标卷。其余路径由独立复核人记录完成证据。终态和快照操作事件一并提交。
- 安全组规则创建必须经过独立审批。同一父安全组的相同规则定义在未失败时由原操作占用。进入外部写入前复核父组归属、申请授权和审批成员代次。已发送的规则只通过远端证据收敛，确认归属及参数后提交规则资产与父组关系。
- 安全组规则撤销同样绑定父组版本与审批。发出写入前比较已审批的规则内容并再次校验本地权限。进入 `applying` 后只读对账。同一规则两轮受信缺失证据在持有当前任务租约时记成功，资产移除和终态事件与操作同事务提交。
- 安全组删除须明确确认组内规则的移除，由独立审批人批准。删除活动期间阻止规则创建和撤销。两次连续完整的精确缺失证据确认后，在同一事务标记父组与现有组内规则删除，并提交操作终态和发件箱。规则盘点先锁定已知父组，再过滤父组已确认删除的记录，以阻止迟到页写回已删除的规则。
- 弹性公网 IP 释放绑定资源 ID、IPv4 地址和归属版本，必须独立审批。Worker 核对厂商确认的未绑定状态后记录发送，再发出至多一次释放请求。两轮连续完整的精确查询均找不到资源时，事务内提交资产移除、操作成功和发件箱事件。
- 弹性公网 IP 绑定与解绑同时固化公网 IP 和实例归属版本，必须独立审批，并与同实例删除互斥。记录发送后只读对账，绑定要求原 IPv4 地址与目标实例及适用网卡匹配，解绑要求原 IPv4 地址仍存在且关联已清空。连续两轮确认后，持有当前任务和盘点作用域锁的事务更新拓扑、终态与发件箱，并隔离旧盘点结果。
- OpenStack 控制台授权从 `awaiting_approval` 进入 `approved` 或 `rejected`。申请人一次性领取时先提交 `in_use` 与审计，再调用 Nova。连接结束进入 `closed` 或 `failed`。可撤销的授权进入 `revoked`，到达有效期的待处理记录显示 `expired`。转发周期内失去会话或原授权条件会关闭连接。
- AWS 串口授权沿用申请和独立审批状态。申请绑定公钥指纹。发放时先提交 `in_use` 与审计，再向厂商发送一次请求。可信成功回执将授权终结为 `key_sent`，无法确认结果时终结为 `dispatch_unknown`。两个终态均禁止重新领取。进程中断时保留 `in_use`，运维按审计和厂商记录核查。撤销仅能阻止尚未领取的发放。
- 公网 DNS 地址与 TTL 修改在申请时固定托管区归属、原记录快照及目标值，需独立审批。与同区创建、启停、删除共用预约。派发后只读观察同一记录的目标地址、TTL 和原稳定状态。持有任务租约时，在同一事务废弃原快照、结算终态并发布事件。待复核继续占用托管区预约。

- 对象桶加密固定桶创建时间、归属版本和 `unconfigured` 前置状态。独立审批后与版本控制变更共用同桶互斥。确认远端为 AES256 后，同事务发布加密观测、操作终态和发件箱。已登记派发的操作只读对账，需复核时保留互斥。

- 费用分摊预览固定账单版本及摘要、规则摘要和当前分摊版本，读取原账单进行计算。归属项目管理员使用预览返回的摘要和版本发布。相同规则返回历史原收据，新规则在账号锁内核对当前版本后提交分摊账本和项目审计。审计写入失败时一并回滚。

- 恢复时冻结写入，核对仍可能生效的云请求与原账本。旧租约拒绝提交本地状态，已发出的云请求以厂商观察结果对账。回切依据真实云端终态和指定水位。
