# 云资源管理首发范围

产品以 PostgreSQL 为本地账本。API 提交资源意图，Worker 调用外部写接口，控制器发现、观察和对账。控制台、CLI 和 SDK 共享同一 API。独立构造显式注入存储、身份、凭据和厂商客户端。

资产以厂商、规范化远端账号及分区、地域或全局命名空间、资源种类、外部 ID 为唯一键。授权以本地租户和项目为边界。云账号归属项目可以显式授权给同租户其他项目。观察、平台管理和外部管理使用单独的资源模式，接管需要权限和审批。

优先推进腾讯云、阿里云和华为云。AWS EC2 与 OpenStack 也在适配和沙箱验收范围内。各厂商的资源、动作和验收状态见能力矩阵。审批者与申请者分别校验，地域和账号为写入放量单位。凭据保存外部引用，默认只读，厂商写授权有独立开关。
