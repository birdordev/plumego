# 验收合同

| 阶段 | 用例和要求 |
| --- | --- |
| 账号与授权 | 双租户及同租户多项目，覆盖无成员、观察者、操作者、审批者、显式分享、禁用、撤权和旧凭据代次。使用真实 PostgreSQL 验证跨租户外键。 |
| Provider 合同 | 按厂商与资源测试分页、重复页、过期或停滞游标、限流、权限变化、缺失、未知结果。AWS 验证跨账号身份与令牌作用域。OpenStack 验证服务目录和 Nova 异步终态。 |
| VMware vSphere | 核对 vCenter UUID、证书和数据中心范围，逐类验证数据中心、VM、模板、网络及项目拓扑。验证会话清理、后页失败、跨进程续跑、凭据轮换、权限收缩与写入拒绝。真实站点另验收权限层级、版本、容量和会话限额。 |
| 持久盘点 | 真实 PostgreSQL 验证分页断电、同作用域并发扫描和重领。失败、权限收缩和迟到回包产生零误移除。重复扫描后资产唯一。 |
| 云端操作 | 在真实隔离沙箱核对请求参数、厂商状态和本地账本。覆盖重复受理、外部提交后断连、发送后进程退出、旧 Worker、审批撤销、依赖冲突和补偿。 |
| 腾讯云 CVM 退役 | 隔离沙箱核对按量付费、关机、已知系统盘、已卸载数据盘和销毁保护。验证错认实例、并发互斥、回收态、已受理断连、两轮完整空集及系统盘盘点。 |
| 托管数据库改名 | 腾讯云 MySQL、PostgreSQL、SQL Server，阿里云和华为云 RDS 分别验证写入开关、独立审批、当前名称与归属、同键重放、远端名称漂移、回执丢失后续查及终态发件箱。沙箱验收逐项核对地域、权限和厂商可操作状态。 |
| 托管缓存改名 | 分别验证腾讯云 Redis、阿里云 Tair 和华为云 DCS 的名称字段、写入开关、独立审批、归属版本、只读续查、同键回放、远端漂移、迟到盘点隔离和发件箱。真实云沙箱按账号和地域验证厂商状态和权限。 |
| 原生控制台 | 分别在真实 OpenStack 与 AWS 站点验证独立审批、原申请人一次性领取、审批撤权、授权过期和审计。OpenStack 验证同源 noVNC 与活动连接撤销，AWS 验证目标实例与地域、SSH 主机指纹、短时连入及云端发放记录。 |
| 企业、混合云与治理 | 增加资源与动作后分别验收权限、版本、恢复、控制台和 CLI/API 一致性。账单按账期和原币种重放对账。验证站点失联、Kubernetes 游标恢复和站点间隔离。 |
| 外部工单 | 核对已受理操作保留原策略、不同项目间隔离、外部回执严格递增、平台独立审批及发送前有效性。注入签名投递重试、并发回执、过期、撤权和审计故障。正式启用前在目标工单系统核对申请、批准、撤回和工单版本映射。 |
| CMDB 同步 | 用独立来源库和镜像库验证项目授权、拓扑端点隔离、跨页一致性、读取中撤权、缺失待确认、回执失败回滚及乱序导入。接收端从完整快照计算集合差异。按目标 CMDB 的资源标识、关联映射、定时频率和权限边界验收。 |
| KVM 宿主机放置 | 验证代理 UUID 与代次、过期观测、故障域和主机亲和约束、网络与本地池、GPU 型号及数量。真实 PostgreSQL 验证多副本并发零超卖、幂等键、过期回收、审计失败回滚和租户隔离。真实 Linux 宿主机仍需核对 libvirt 只读权限和专用磁盘容量。 |
| KVM 宿主机隔离 | 验证旧代次和隔离期间的当前代次均无法上报或领取动作，审批绑定现场证据和宿主机版本。核对未决命令和预留保留、审计失败回滚、替换代理及新容量上报。现场验证带外隔离和已发命令收敛。 |
| KVM 隔离任务清单与虚拟机恢复 | 两副本 PostgreSQL 验证正常宿主机空清单、项目隔离、带代次分页、CLI 续读、待审批恢复追踪、任务处置后解除阻塞与错误宿主机或旧代次游标拒绝。覆盖两份缺失证据、独立审批、旧版本、账本失败时预留回滚、确认缺失后 IPv4 重新分配以及原启动卷防复用。真实宿主机验证隔离证据、域观测和启动卷占用。 |
| KVM 已纳管域容量 | 使用 PostgreSQL、两副本及 TLS 代理夹具验证已运行 VM 保留原预留并可继续放置。覆盖未知域、漂移、局部失败、采样取消、域列表变化、旧管理版本、代理换绑及跨项目访问拒绝。真实 Linux 宿主机仍需验证运行态 XML 和采样时延。 |
| KVM 创建 | 验证持久占用、独立审批、相同预留重放、启动卷独占、错误域、两副本竞抢和旧代理拒绝。注入定义和启动后的断连，重连仅凭匹配的 libvirt 状态推进。真实 Linux 宿主机另验收权限、启动卷、访客启动和实际网络访问。 |
| KVM 站点镜像分发 | TLS 和临时文件验证项目站点身份、控制面令牌隔离、重定向拒绝、截断与多余字节、摘要不符、撤权、取消和原文件复用。PostgreSQL 验证已登记镜像从命令导入并用于启动卷。按目标站点验收证书、镜像目录权限和传输容量。 |
| KVM 镜像启动卷 | 在 PostgreSQL、TLS 和真实临时文件上验证项目隔离、审批、不可变镜像绑定、同卷锁竞争保留原观测、错误摘要、软链接与不同目标拒绝、授权撤销、发布中断、刷新回执丢失后核对和已发布内容漂移拦截。真实 Linux 上验收受支持卷池、文件权限、池刷新及访客镜像启动。 |
| KVM 优雅关机 | 在 PostgreSQL、两副本 TLS 和代理夹具上覆盖强版本并发、独立审批、撤权、排空和换绑、临时域及缺少 ACPI 拒绝、单次 ACPI 派发、回执丢失后只读恢复、审计回滚和占用保留。真实宿主机验证访客收到 ACPI 事件和异步关机。 |
| KVM 退役 | 在 PostgreSQL、两副本 TLS 和代理夹具上覆盖管理员和独立审批、旧版本、域保护、单次移除域定义、回执丢失、两轮缺失、复现重置、审计回滚、容量重新分配和保留卷防复用。真实宿主机验证依赖检查、状态文件与启动卷均被保留。 |
| KVM 冷迁移 | 两副本 PostgreSQL、TLS CLI 和 libvirt 夹具验证已确认缺失、过期预留、独立并发审批、事务回滚、原 VM ID 和 IP 保留、旧代理拒绝、原预留提交重放、raw 恢复及定义和启动回执丢失。真实宿主机核对停机一致性备份、访客数据和目标网络。 |
| KVM 源端备份 | 验证未结束任务、错误代理、旧版本、符号链接、内容变化和发布前撤权均拒绝，重复导出复用摘要文件。冷迁移验收登记源代理实际导出的内容，再由目标代理恢复。真实宿主机核对卷独占和备份可恢复性。 |
| KVM 故障疏散 | 使用满地址池和两个宿主机夹具验证隔离未确认及旧代次拒绝、管理员专用预留、原 IPv4 和 MAC 原子转移、审计失败回滚、源代理拒绝、目标备份恢复和现场清理前拒绝源重新接入。真实站点验收带外隔离、备份恢复点和物理网络。 |
| KVM 疏散自动选址 | 两副本 PostgreSQL 验证排除同故障域、候选锁竞争、容量不足、6 路同 ID 只生成一条预留、申请失败回滚、独立拒绝释放容量，以及批准后由目标代理恢复。真实站点验收备份分发和跨故障域容量。 |
| KVM 批量疏散 | 两副本 PostgreSQL 验证隔离和版本、重复 VM 拒绝、单项容量不足与账本失败时整批回滚、并发同 ID 只受理一次，以及两台 VM 独立审批和 CLI 查询。真实站点验收批量恢复时的目标容量及备份分发。 |
| KVM IPv4 地址池 | 在 PostgreSQL 和两副本上验证作用域、子网冲突、跨宿主机并发唯一性、地址与容量原子预留、到期封存、绑定跨 TTL、拒绝冲突和退役回收。TLS 代理夹具验证生效配置与持久配置漂移、重复静态映射、动态范围重叠和 VM 网卡 MAC。真实 Linux 宿主机验收静态 DHCP、访客可达性和二层隔离。 |
